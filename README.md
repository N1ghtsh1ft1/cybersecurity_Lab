# Cybersecurity Lab

A personal cybersecurity lab and study repo — notes, exercises, scripts, and configs used while learning and practicing security concepts.

## Contents

- [`docs/`](docs/README.md) — study notes and reference material, organized by topic/certification track

## Scope

This repo is for learning and authorized practice only: CTF writeups, lab exercises, certification study notes (e.g. Security+), and tooling used in sandboxed or explicitly authorized environments. Nothing here targets systems without permission.
